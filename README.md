# Уроки математики

Интерактивные уроки по школьной математике. Каждый урок — один самодостаточный HTML-файл (без сервера и сборки), поэтому проект публикуется как статический сайт на GitLab Pages.

## Уроки

- [Многочлены: стандартный вид, сложение и вычитание](polynomials.html)
- [Умножение одночленов и возведение в степень](monomial-multiplication.html)
- [Уравнения высших степеней](higher-degree-equations.html)
- [График квадратичной функции](quadratic-function-graph.html)
- [Основное тригонометрическое тождество](pythagorean-trig-identity.html)

Страница `index.html` — список всех уроков.

## Локальный просмотр

Откройте `index.html` в браузере. Шрифты (Caveat, PT Sans) подгружаются из Google Fonts; без интернета используются системные.

## Публикация

Файл `.gitlab-ci.yml` содержит задание `pages`: оно копирует `*.html` в `public/` и запускается при пуше в ветку по умолчанию. Сайт доступен по адресу из раздела Deploy → Pages.

## Добавление урока

1. Положите новый `.html` файл в корень репозитория.
2. Добавьте ссылку в `index.html` и в этот README.
