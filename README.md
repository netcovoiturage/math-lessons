# Уроки математики

Интерактивные уроки по школьной математике. Каждый урок — один самодостаточный HTML-файл (без сервера и сборки), поэтому проект публикуется как статический сайт на GitLab Pages.

## Уроки

Уроки сгруппированы по классам — у каждого класса своя папка и страница-список.

- **7 класс** — [список](grade-7/)
  - [Многочлены: стандартный вид, сложение и вычитание](grade-7/polynomials.html)
  - [Умножение одночленов и возведение в степень](grade-7/monomial-multiplication.html)
  - [Три признака равенства треугольников](grade-7/triangle-congruence.html)
- **9 класс** — [список](grade-9/)
  - [График квадратичной функции](grade-9/quadratic-function-graph.html)
- **10 класс** — [список](grade-10/)
  - [Уравнения высших степеней](grade-10/higher-degree-equations.html)
  - [Основное тригонометрическое тождество](grade-10/pythagorean-trig-identity.html)

Страница `index.html` — выбор класса; общие стили лежат в `style.css`.

## Локальный просмотр

Откройте `index.html` в браузере. Шрифты (Caveat, PT Sans) подгружаются из Google Fonts; без интернета используются системные.

## Публикация

Файл `.gitlab-ci.yml` содержит задание `pages`: оно копирует `index.html`, `style.css` и папки `grade-*` в `public/` и запускается при пуше в ветку по умолчанию. Сайт доступен по адресу из раздела Deploy → Pages.

## Добавление урока

1. Положите новый `.html` файл в папку нужного класса (`grade-N/`); для нового класса создайте папку `grade-N/` с `index.html` по образцу соседних.
2. Добавьте карточку урока в `grade-N/index.html` (и карточку класса в корневой `index.html`, если класс новый).
3. Обновите список в этом README.
