Уравнения высших степеней

Уравнения, где x стоит в степени 3, 4 и выше. Пять способов решения — от самого простого к самому сложному. Выбирай способ, нажимай «Следующий шаг» и смотри на график: корни — это точки, где график пересекает ось Ox.

Главная мысль: уравнение степени n имеет не больше n корней. Уравнение третьей степени — не больше трёх корней, четвёртой — не больше четырёх.

🩺

Где это пригодится врачу

Многие клетки (например, лимфоциты) по форме близки к шару. Объём шара V = 4⁄3·πr³.

Пусть объём клетки V = 36π мкм³. Найдём радиус: 4⁄3·πr³ = 36π → r³ = 27 → r = 3 мкм.

Это уравнение третьей степени вида xⁿ = a — самый первый способ.

Тренажёр: подбери корень

Целый корень надо искать среди делителей свободного члена (числа без x). Нажимай на делители — увидишь подстановку. Если получилось 0, это корень.

    Какой способ выбрать?

    1. Вид xⁿ = a → извлекаем корень (следим за чётностью n).
    2. Нет числа без x → выносим x за скобку.
    3. Четыре слагаемых → пробуем группировку.
    4. Только x⁴, x² и число → замена t = x².
    5. Ничего не подходит → подбираем корень среди делителей свободного члена и делим.

    Частые ошибки

    Делим обе части x³ = 4x на x
    Так теряется корень x = 0. Нужно перенести всё влево и вынести x.
    x⁴ = 16, значит x = 2
    Степень чётная, корней два: x = 2 и x = −2.
    x³ = −8 не имеет корней
    Степень нечётная, корень есть: x = −2, ведь (−2)³ = −8.
    t = x² = −1, значит x = ±1
    x² не бывает отрицательным. Такое t отбрасываем.
