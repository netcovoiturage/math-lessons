График квадратичной функции

Парабола шаг за шагом: от самой простой y = x² до общего вида y = ax² + bx + c. Выбирай уровень и двигай ползунки — смотри, что происходит с графиком.

Пунктир — график y = x² для сравнения.

Как построить параболу: алгоритм

Построим график y = x² − 4x + 3. Нажимай «Следующий шаг» — на графике будет появляться то, что мы нашли.

  1. Смотрим на a. Здесь a = 1 > 0, значит ветви вверх.
  2. Вершина: x₀ = −b / (2a) = 4 / 2 = 2. Подставляем: y₀ = 2² − 4·2 + 3 = −1. Вершина (2; −1).
  3. Через вершину проводим ось симметрии x = 2.
  4. Пересечение с осью Oy: ставим x = 0, получаем y = c = 3. Точка (0; 3).
  5. Нули функции: x² − 4x + 3 = 0, корни x = 1 и x = 3.
  6. Точку (0; 3) отражаем относительно оси симметрии: получаем (4; 3).
  7. Соединяем точки плавной линией. Парабола готова!

Знаки a, b и c по графику

a: ветви вверх → a > 0; ветви вниз → a < 0.

c: где парабола пересекает ось Oy. Выше нуля → c > 0, ниже → c < 0, в начале координат → c = 0.

b: смотрим, где вершина. Вершина справа от Oy → у a и b разные знаки. Слева → одинаковые. На оси Oy → b = 0.

    Частые ошибки

    y = (x − 3)² сдвинут влево
    Нет, вправо на 3. Минус в скобке — сдвиг вправо.
    a < 0 — ветви вверх
    Наоборот: минус перед x² — ветви вниз.
    x₀ = b / (2a)
    Не забывай минус: x₀ = −b / (2a).
    c — это вершина
    c — это пересечение с осью Oy. Вершиной (0; c) будет только при b = 0.
