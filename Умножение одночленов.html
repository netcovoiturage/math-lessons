Умножение одночленов и возведение в степень

Одночлен — это произведение чисел и букв, например 5x², −a³b, 13y. Сегодня учимся их перемножать и возводить в степень.

Три главных правила

1. Умножение степеней

am · an = am + n

Основания одинаковые — показатели складываем.

2. Степень в степени

(am)n = am · n

Показатели перемножаем.

3. Степень произведения

(ab)n = anbn

В степень возводим каждый множитель, и число тоже.

Посмотри, откуда берутся правила

Степень — это просто короткая запись умножения: a³ = a·a·a. Двигай ползунки и считай квадратики.

Знак: чётная и нечётная степень

Минус в чётной степени исчезает: (−2)² = 4, (−x)⁴ = x⁴.

Минус в нечётной степени остаётся: (−2)³ = −8, (−x)⁵ = −x⁵.

При умножении считаем минусы: чётное число минусов → «+», нечётное → «−».

Алгоритм умножения одночленов

  1. Определи знак ответа.
  2. Перемножь числа.
  3. Одинаковые буквы: сложи показатели.
  4. Запиши буквы по алфавиту.

Разбираем задачи из учебника

Нажимай «Дальше» в каждой карточке.

а) 1,5x · 8x
  1. Знак: минусов нет → «+».
  2. Числа: 1,5 · 8 = 12.
  3. Буквы: x · x = x1+1 = x².
  4. Ответ: 12x²
б) −a² · 4a³
  1. Знак: один минус → «−».
  2. Числа: 1 · 4 = 4.
  3. Буквы: a² · a³ = a2+3 = a⁵.
  4. Ответ: −4a⁵
в) 6y · (−13y²)
  1. Знак: один минус → «−».
  2. Числа: 6 · 13 = 63 = 2.
  3. Буквы: y · y² = y1+2 = y³.
  4. Ответ: −2y³
г) (−2a²b)³
  1. Степень 3 — нечётная, значит минус остаётся.
  2. Число: 2³ = 8.
  3. a²: (a²)³ = a2·3 = a⁶.
  4. b: b³.
  5. Ответ: −8a⁶b³

Частые ошибки

a² · a³ = a⁶
При умножении показатели складывают: a⁵.
(a²)³ = a⁵
При возведении в степень показатели перемножают: a⁶.
(3x)² = 3x²
В степень возводится и число: 9x².
(−x)⁴ = −x⁴
Степень чётная — минус исчезает: x⁴.
2x · 3x = 5x²
Числа умножают, а не складывают: 6x².
